# Atajos de LazyVim

La tecla líder es `<Space>`. Los atajos de LazyVim se muestran al pulsar `<Space>` y esperar un instante.

| Tecla | Acción |
|---|---|
| `<C-s>` | Guardar archivo |
| `<C-p>` | Buscar archivos |
| `<Space>fg` | Buscar texto en el proyecto |
| `<Space>fw` | Buscar palabra bajo el cursor |
| `<Space>fb` | Buscar buffers abiertos |
| `<C-b>` o `<Space>e` | Abrir explorador de archivos |
| `<Space>gg` | Abrir LazyGit del proyecto actual |
| `<Space>gd` | Ver diff Git del archivo |
| `<Space>ca` | Acción de código, incluido importar símbolo |
| `<Space>cf` | Formatear archivo |
| `<Space>cr` | Renombrar símbolo |
| `gd` / `gr` / `K` | Definición / referencias / documentación |
| `]d` / `[d` | Diagnóstico siguiente / anterior |
| `<Space>?` | Abrir esta guía |
| `<Space>fk` | Buscar cualquier atajo |

Para un auto-import en TypeScript o JavaScript, escribe parte del símbolo, espera la sugerencia y confírmala. Si no aparece, usa `<Space>ca`.

Warp intercepta `<C-Shift-f>`, por lo que la búsqueda global se hace con `<Space>fg`.
